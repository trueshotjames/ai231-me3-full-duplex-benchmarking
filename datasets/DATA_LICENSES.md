All clips are derived from the Full-Duplex-Bench v1.0 and v1.5 release by Lin et al.
(https://github.com/DanielLin94144/Full-Duplex-Bench, dataset README), built by `tools/build_datasets.py`:

| Set | Origin | Licence |
|---|---|---|
| v1 pause handling (Candor), v1 turn-taking (Candor) | Candor corpus clips selected by the authors | CC BY-NC 4.0 (non-commercial, with attribution); Candor terms of use also apply |
| v1 pause handling (synthetic), v1 user interruption | synthesized by the authors | MIT |
| v1.5 interruption, backchannel, talking to others, background speech | synthesized by the authors | MIT |
| false turn-taking: side talk, background speech | overlap windows cut from the v1.5 clips | MIT |
| false turn-taking: TV / radio | v1 interruption speech processed by this tool | MIT |
| false turn-taking: noise | synthesized by this tool | MIT |
